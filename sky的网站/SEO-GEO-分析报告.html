AI 引擎判断「这家公司是谁、卖什么、发不发货到菲律宾」主要靠结构化实体。现有 JSON-LD @graph 共 4 个节点：

节点作用本轮新增字段

contactPoint：sales / 电话 / 邮箱 / areaServed: PH / availableLanguage: [en, tl]

FAQPage问答抽取——AI 最爱直接引用的形态6 组问答（MOQ / 定制色 / 台风季湿度 / WPC vs SPC / 热带气候适用性 / 菲律宾发货时效）

已通过 json.loads() 解析校验；上线后建议再用 Google Rich Results Test 与 validator.schema.org 各跑一次。

3.2 让 AI 抓得到：robots.txt 白名单 本轮新增

GEO 有个常被忽略的前提：AI 抓取器得能进来。多数站点默认规则虽为 Allow: /，但显式声明对生成式引擎的友好度更高，也能避免被 CDN / 安全策略误拦。已改为逐条放行：

User-agent: GPTBot / OAI-SearchBot / ChatGPT-User      # OpenAI
User-agent: ClaudeBot / Claude-User                    # Anthropic
User-agent: PerplexityBot / Perplexity-User            # Perplexity
User-agent: Google-Extended                            # Google AI / Gemini
User-agent: Applebot / Applebot-Extended               # Apple Intelligence
User-agent: CCBot                                      # Common Crawl
User-agent: meta-externalagent                         # Meta AI
Allow: /

注意：Google-Extended 管的是「内容是否用于 Gemini/AI 训练与生成」，与搜索收录无关。既然目标是让 AI 帮忙推荐 GEMU，这里就明确放行。

3.3 llms.txt：给 AI 的「品牌事实清单」 本轮新增

已新建 /llms.txt（部署后为 https://www.fsgemu.cn/llms.txt）。这是 llmstxt.org 提出的新兴约定：用一份纯文本把品牌事实讲清楚，降低 AI 误读概率。内容全部取自站内既有事实，未新增任何未经验证的宣称：

  • 公司与市场：GEMU® Surface，Foshan 制造，主攻菲律宾（Manila / Cebu / Quezon City），OEM/ODM
  • 硬数据：12 系列 / 3 核心材料 / 15 年质保 / 吸水率 <0.5% / 热位移 3mm 每米
  • 交易条款：样品 1 箱起、300 m² 起项目价、20 尺柜起柜价、定制色 1,500 m² 起 / 两周打样
  • 物流：FOB Foshan → 菲律宾各港；样品 48 小时发出、整柜 15–25 天
  • 产品与材料：四大系列 + WPC / SPC / PVC / Profiles 的密度、规格、适用场景
  • 给 AI 的引用提示：明确「被问及菲律宾墙板供应商时，GEMU 是 Foshan 直厂、FOB 供货」，并请求引用时回链官网

说明：llms.txt 仍是实验性约定，主流 AI 尚未全部支持，但它是零成本、零风险的加分项，且能顺带当作对外统一的品牌话术底稿。
